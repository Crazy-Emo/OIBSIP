# Landing Page: Tuma

Task 1 of Level 1, Web Development and Designing, Oasis Infobyte SIP.

A static landing page for Tuma, a concept product that turns a WhatsApp message from a small shop owner into a live update on their website. Built with HTML5 and CSS3 only, no JavaScript.

## The idea

Small businesses in Kenya already run on WhatsApp, but their websites go stale because updating them is a chore. Tuma lets the owner text a new price, a new product, or a sold out item, and the website changes.

## Feature checklist

- Sticky navigation bar with 3 section links and a call to action
- Hero with a headline, subheadline, and call to action button
- Hero demo built in pure CSS: a message is sent, Tuma replies, and a new product appears on the shop page (10 second loop)
- Content sections: Why Tuma, How it works, What you can send
- Footer with placeholder contact and social links
- One colour palette across every section (ink, mist, signal green, marigold)
- Responsive with Flexbox and CSS Grid, checked at 390px wide
- Intentional padding, margin, and `box-sizing: border-box` on every element
- Two typefaces (Familjen Grotesk for headings, Instrument Sans for body) with a clear size scale
- The loop switches off for people who prefer reduced motion and shows the finished state instead

## Run it

Open `index.html` in a browser. No build step.

## Notes

Tuma is a concept, and the contact links are placeholders.
