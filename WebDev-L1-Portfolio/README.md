# Personal Portfolio

Task 2 of Level 1, Web Development and Designing, Oasis Infobyte SIP.

A one page portfolio for Masanori (Shiesty), a web developer and brand designer in Nairobi. Built with HTML5 and CSS3 only.

## Feature checklist

- Hero with name, role title, and an avatar placeholder
- About section
- Skills section, grouped into front end, back end, languages, and design
- Projects section with 3 project cards (title, description, stack, link)
- Contact section with email, GitHub, and LinkedIn
- Smooth scroll navigation between sections
- Black, gold, and cream palette with Cinzel and Jost used throughout
- Responsive on desktop and mobile

## Run it

Open `index.html` in a browser. No build step.

## Notes

The email address and two GitHub project links are placeholders to replace with real ones. The third project card links to the Landing Page task in this repository.
